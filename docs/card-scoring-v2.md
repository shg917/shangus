# 4축 카드 v2 임시 환산 기준

fix/card-design에서 사용하는 게임 밸런스 초안입니다. 체력 백분위 자료를 근거로 한 기준이 아닙니다.
체중·남성/여성 계산 기준과 최소 한 종목을 입력합니다. 네 축을 모두 측정할 필요는 없습니다.
종목별 점수는 0~100이고, 같은 축은 가장 높은 점수를 사용합니다. 미측정 축은 null입니다.

| 축 | 종목 | 0점 기준 | 100점 기준 | 측정 방법 |
| --- | --- | --- | --- | --- |
| 근력 | O.H.P | 0 | 체중 × 1.1 | 1RM 또는 중량·반복 |
| 근력 | B.P | 0 | 체중 × 1.7 | 1RM 또는 중량·반복 |
| 근력 | D.L | 0 | 체중 × 2.8 | 1RM 또는 중량·반복 |
| 근력 | SQ | 0 | 체중 × 2.5 | 1RM 또는 중량·반복 |
| 근지구력 | 푸시업 | 0회 | 60회 | 연속 수행 |
| 근지구력 | 풀업 | 0회 | 20회 | 반동 없이 연속 수행 |
| 근지구력 | 싯업 | 0회 | 60회 | 1분 |
| 순발력 | 제자리 멀리뛰기 | 150cm | 280cm | 도약선~뒤쪽 발뒤꿈치 |
| 순발력 | 서전트 점프 | 20cm | 75cm | 점프 도달 높이 − 서서 뻗은 손 높이 |
| 심폐지구력 | 3KM | 21분 | 10분 | 완주 시간 |
| 심폐지구력 | 5KM | 35분 | 18분 | 완주 시간 |
| 심폐지구력 | 10KM | 80분 | 38분 | 완주 시간 |
| 심폐지구력 | 하프 | 3시간 | 1시간 30분 | 21.0975km 완주 |
| 심폐지구력 | 풀 | 6시간 | 3시간 10분 | 42.195km 완주 |

구간 사이 점수는 선형으로 계산하며 범위 밖 점수는 0~100으로 제한합니다.
중량 2~12회는 중량 × (1 + 반복/30)으로 1RM을 추정합니다.
기존 여성 근력 계수 0.62를 유지했습니다. 다른 종목은 동일 기준입니다.
입력 시간은 분:초 또는 시:분:초이며 초 단위 숫자도 받습니다. DB에는 초로 저장합니다.
부분 기록의 기본 전투 스탯, 최고 점수로 정하는 클래스, 새 기록의 HP 상한 처리 등 기존 전투 규칙을 유지합니다.

## SQL 배포

`supabase/migrations/20261118081058_card_four_axes.sql`을 기존 3개 마이그레이션 다음에 적용합니다.
SQL Editor에서도 파일 전체를 한 번 실행할 수 있습니다. 별도 적용 시 CLI 이력도 동기화해야 합니다.
이번 작업 브랜치에서 원격 Supabase에는 적용하지 않았습니다.
새 종목으로 계정 저장하려면 새 SQL을 프론트 배포 전에 적용해야 합니다.

과거 카드의 입력·점수·버전과 기존 플레이어의 전투 상태는 변경하지 않습니다.
플랭크 정의는 과거 기록의 외래키 참조를 위해 비활성 상태로 보존합니다.
새 기록은 v2로 발급합니다. 기존 v1 카드는 4축 값만 표시하며 종목별 점수를 새로 계산해 덮어쓰지 않습니다.
