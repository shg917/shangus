# 60초 보스 공략 초안

4축 카드의 근력·근지구력·순발력·심폐지구력 점수를 공격력·클릭당 타격 수·치명타 확률·최대 HP로 사용합니다.

- 10명의 보스를 순서대로 공략합니다.
- 도전 1회는 60초이며 보스는 2초마다 자동 반격합니다.
- 클릭 1회마다 현재 능력치의 타격 수·공격력·치명타를 적용합니다.
- 보스가 쓰러지면 초과 피해는 다음 보스로 이어집니다. 10번 처치로 완료합니다.
- HP가 0이 되거나 시간이 끝나면 종료합니다. 보스의 HP는 유지합니다.
- 하루 기본 플레이 1회, 이후 부활권 1장으로 다시 시작합니다.
- 부활은 내 HP와 60초를 회복하며 보스의 남은 HP와 처치 수는 유지합니다.
- 로그인·운동 기록 퀘스트의 기존 부활권 보상과 잔액을 공유합니다.

| --- | --- |
| 프로틴 괴물 | 100,000 |
| 덤벨 도둑 | 400,000 |
| 치팅 밀 포식자 | 1,200,000 |
| 원판 수집가 | 3,000,000 |
| 카페인 폭주자 | 8,000,000 |
| 랙 점령자 | 20,000,000 |
| 벌크업 대장 | 50,000,000 |
| 유산소 파괴자 | 125,000,000 |
| 무한 세트 장인 | 300,000,000 |
| 헬스장 최종 고인물 | 750,000,000 |

HP는 초기 게임 밸런스이며 실제 사용자의 클릭 속도와 기록 분포에 따라 조정할 수 있습니다.
반격 피해는 12 + 보스 번호 × 4입니다.

## 저장과 통신

서버 시각으로 도전 시작·종료와 반격을 판정합니다. 화면 이동·새로고침·접속 종료로 시간이 정지하지 않습니다.
경과 반격은 다음 상태 조회/공격 때 서버에서 정산합니다.
브라우저는 클릭 수를 즉시 누적하고 200ms마다 서버와 동기화합니다.
서버는 도전 ID와 누적 클릭 수를 확인해 재시도·중복·순서가 뒤바뀐 요청의 이중 피해를 방지합니다.
응답을 잃은 요청은 같은 UUID로 재전송합니다. 처리 중 추가 클릭은 다음 누적 요청에 포함합니다.
조작된 대량 요청을 제한하는 기술적 상한은 초당 30회(1초 여유), 도전당 1,800회입니다.
제한 시간 직전의 요청은 서버에 도착한 시간을 기준으로 인정합니다.

기존 9,999층 진행도와 랭킹은 그대로 보존합니다.
새 모드는 private.click_players, private.click_rankings에 별도 저장하며 첫 보스부터 시작합니다.
회원·카드·부활권·일일 기본 플레이 사용 이력은 기존 자료를 사용합니다.
